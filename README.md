# 表策（Biaoge Report）

一个完全在浏览器本地运行的 CSV 销售周报生成器。导入订单表后，自动生成销售额、有效订单、客单价、退款、每日趋势、渠道排行和商品排行。

## 适用场景

- 微信小店、淘宝、抖音商城等渠道的周期销售复盘
- 小型商家、工作室、个体经营者的订单汇总
- 需要固定格式经营周报的代运营或财务助理

## 隐私

CSV 文件只在当前浏览器中读取和计算，不会上传服务器。页面刷新后，导入数据即清除。

## 本地使用

直接打开 `index.html`，或者通过任意静态文件服务器访问。项目无构建步骤、无第三方运行时依赖。

## 字段识别

支持日期、金额、商品、渠道、订单号、订单状态和退款金额等常见中英文字段。至少需要一个金额字段。

## 商业模式

免费工具承担获客和需求验证；收入来自订单格式适配、指标口径定制及持续数据服务。具体边界和报价见 `OFFER.md`。
