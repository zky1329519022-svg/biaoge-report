# 表策（Biaoge Report）

把 CSV 订单表变成清晰的经营周报。所有计算都在浏览器本地完成，无需注册，也不会上传客户数据。

[下载最新版本](../../releases/latest) · [申请订单表适配](../../issues/new?template=service-request.yml&title=%5B%E4%B8%80%E6%AC%A1%E6%80%A7%E9%80%82%E9%85%8D%5D+) · [申请月度数据服务](../../issues/new?template=service-request.yml&title=%5B%E6%9C%88%E5%BA%A6%E6%9C%8D%E5%8A%A1%5D+)

## 适用场景

- 微信小店、淘宝、抖音商城等渠道的周期销售复盘
- 小型商家、工作室、个体经营者的订单汇总
- 需要固定格式经营周报的代运营或财务助理

## 隐私

CSV 文件只在当前浏览器中读取和计算，不会上传服务器。页面刷新后，导入数据即清除。

## 本地使用

从 Release 下载压缩包，解压后直接打开 `index.html`。项目无构建步骤、无第三方运行时依赖。

## 字段识别

支持日期、金额、商品、渠道、订单号、订单状态和退款金额等常见中英文字段。至少需要一个金额字段。
